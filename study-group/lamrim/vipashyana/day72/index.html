《菩提道次第廣論》毗缽舍那．每日研讀

第 72 天　雙運辨析補完；全道總義；毘缽舍那章終

原文〔0774a15〕–〔0774b24〕．約 1,242 字．法尊法師譯

接昨天同一行。先補完止觀雙運的辨析：雙運要由觀察自力引生堅穩安住，只是「安住不壞、兼能觀空」像小魚游於靜水，不能誤認為雙運。接著宗大師「略說道之總義」：從親近善知識、暇滿、無常與惡趣、皈依、業果，到中士的出離與三學，上士的菩提心、受戒、六度四攝，最後是靜慮與般若——止觀就是從菩薩學處中分出來的。最後提醒：修道要前後相引、圓滿道體，並依自心的缺點調整修習的重點。毘缽舍那章到今天讀完。

今天讀完要記得
  1. 未成奢摩他前，觀察雜修止相不能成就奢摩他；已成奢摩他、未成毘缽舍那前，觀察自力不能引發堅穩專注；能由觀察引得堅穩安住，要得毘缽舍那才有，所以雙運從此建立。「小魚游安靜水」不是雙運。
  2. 道之總義：依師為根本 → 暇滿、無常、惡趣、皈依、業果（下士）→ 生死過患、三學、別解脫戒（中士）→ 菩提心、受願心與行心律儀、六度四攝（上士）→ 最後二度：靜慮與般若，即止與觀，不離後二波羅蜜多而別有。
  3. 修道要「修習下下，漸於上上增欲得心；聽聞上上，而於下下漸欲修行」，對圓滿道體引生定解；並依自心偏差調整重點：不樂修行修暇滿、著現法修無常、輕佛制修業果、缺厭患修生死過患、利他心弱修願心、執相繫縛以理智破、散亂修安住。

原文〔0774a15–a17〕

又將成就毘缽舍那，其前無間由觀察修，有時能引專注一趣，前亦思彼。今此宣說毘缽舍那未成之前，以觀察修不能引生無分別者，除彼例外，意取其前未能成時。

白話§1

又，在將要成就毘缽舍那的前一刻，由觀察修，有時能引生專注一趣，前面也考慮到這一點。現在這裡說毘缽舍那未成之前，以觀察修不能引生無分別，是除去那種例外，意思是取那之前還不能成就的時候。

詳解（1）

一個例外

論文明說「將成就毘缽舍那，其前無間由觀察修，有時能引專注一趣」；這裡說不能引生，是「除彼例外，意取其前未能成時」。

助讀宗大師把界線說得很細：毘缽舍那將成的那一刻，可能已出現觀察引生專注的情形；說「不能」是指更早的階段。

原文〔0774a17–a19〕

總其未成奢摩他前，觀察之後雜修止相，不能成就正奢摩他。若已成就奢摩他後，毘缽舍那未成之前，觀察自力不能引發堅穩安住專注一趣，故以觀慧數數觀察，即由觀察而能引得堅穩住者，要得毘缽舍那乃有，故亦從此建立雙運。

白話§2

總之，在未成就奢摩他之前，觀察之後雜修止相，不能成就正奢摩他。如果已經成就奢摩他之後，在毘缽舍那未成之前，觀察的自力不能引發堅穩安住、專注一趣。所以，以觀慧一再觀察，就由觀察而能引得堅穩安住，要得了毘缽舍那才有；所以也從這裡建立雙運。

詳解（1）

三個階段

拆開看：①未成奢摩他：觀察雜修止相 → 不能成奢摩他；②已成奢摩他、未成毘缽舍那：觀察自力 → 不能引堅穩專注；③得毘缽舍那：觀察即能引堅穩安住 → 建立雙運。

論文明說「即由觀察而能引得堅穩住者，要得毘缽舍那乃有，故亦從此建立雙運」。

原文〔0774a19–a20〕

是故唯於未壞堅穩無分別住，兼能觀察無我空義，猶如小魚游安靜水，不當誤為止觀雙運。

白話§3

所以，只是在沒有破壞堅穩無分別住的情況下，兼能觀察無我空義，就像小魚在安靜的水中游動，不應當誤認為止觀雙運。

詳解（1）

小魚游安靜水

論文明說「唯於未壞堅穩無分別住，兼能觀察無我空義」→「不當誤為止觀雙運」。

助讀水靜（安住）而魚游（微細觀察）：止是主，觀只是不擾動止的附帶活動。雙運要的是反過來，由觀察本身的力量引生堅穩安住。兩者表面相似，主從關係不同。

原文〔0774a20–a22〕

如是止觀雙運之理，應如彼等清淨論典所說而知，餘增益說，非可憑信。由此等門而修止、觀，雖尚可分眾多差別，然恐文繁，故不多述。

白話§4

這樣的止觀雙運的道理，應當如那些清淨的論典所說而了知；其餘增益之說，不可憑信。由這些門徑修止、觀，雖然還可以分出許多差別，但恐怕文字繁多，所以不多說。

原文〔0774a23〕

今當略說道之總義，謂於最初道之根本，即是親近知識道理，故於彼上當善修鍊。

白話§5

現在應當略說道的總義：最初是道的根本，就是親近善知識的道理，所以應當在這上面善加修練。

詳解（1）

從頭收攝

助讀以下宗大師把整部《廣論》從道前基礎到止觀依序收攝一遍，可當作全論的地圖來讀。

論文明說依師是「道之根本」。

原文〔0774a23–a24〕

次於暇身，若起真實取心要欲，彼從內策令恆修行，為生彼故當修暇滿。

白話§6

接著，對於暇滿之身，如果生起真實取心要的意欲，它會從內心策勵自己恆常修行；為了生起它，應當修暇滿。

原文〔0774a24–b02〕

次若未滅求現法心，則於後世不能發生猛利希求，故當勤修人身無常，不能久住，死後流轉惡趣道理。爾時由生真心念畏，便能誠信三寶功德，安住皈依不共律儀，學其應學。

白話§7

接著，如果沒有滅除追求現世的心，就不能對後世生起猛利的希求，所以應當勤修人身無常、不能久住，以及死後流轉惡趣的道理。那時由於生起真心的憶念與怖畏，便能誠信三寶的功德，安住於皈依的不共律儀，學習其應學之處。

詳解（1）

下士道的前半

論文明說未滅「求現法心」→ 不生後世希求 → 修無常、惡趣 → 真心念畏 → 誠信三寶、安住皈依律儀。

現法＝現世、這一生。

原文〔0774b02–b03〕

次於業果當由多門引發堅固深忍信解，是為一切白法根本，勤修十善，滅十不善，相續轉趣四力之道。

白話§8

接著，對於業果，應當從多方面引發堅固而深切的忍可信解，這是一切白法的根本；勤修十善、滅除十不善，相續地趣入四力之道。

詳解（1）

四力

助讀四力＝懺淨罪業的四種力：破壞現行力（追悔）、對治現行力、遮止罪惡力（防護）、依止力（皈依、發心）。在下士道業果處講過。

論文明說業果的信解是「一切白法根本」。

原文〔0774b03–b06〕

如是善修下士法已，當多思惟，若總若別生死過患，總於生死令心厭捨。次觀生死從何因生，當識煩惱及業自性，發起真實樂斷之欲，便於真能解脫生死三學總道能引定解，特於所受別解脫戒當勤修學。

白話§9

這樣善修下士法之後，應當多思惟總的與別的生死過患，總之令心厭捨生死。接著觀察生死從什麼因生起，應當認識煩惱以及業的自性，生起真實樂於斷除的意欲，便能對真正能解脫生死的三學總道引生定解，特別對自己所受的別解脫戒，應當勤加修學。

詳解（1）

中士道

論文明說思惟生死過患 → 厭捨生死 → 認識煩惱與業 → 樂斷 → 對三學總道生定解 → 特於別解脫戒勤學。

三學＝戒、定、慧。

原文〔0774b06–b08〕

如是善學中士法已，作意思惟，如自墮落三有苦海，眾生皆爾，應當勤修慈悲為本大菩提心，必令生起。若無此心，其六度行、二次第等，皆如無基而建樓閣。

白話§10

這樣善學中士法之後，作意思惟：如同自己墮落在三有苦海，眾生也都是這樣；應當勤修以慈悲為根本的大菩提心，一定要讓它生起。如果沒有這個心，那六度行、二次第等，都像沒有地基而建樓閣。

詳解（1）

菩提心是地基

論文明說無菩提心，「其六度行、二次第等，皆如無基而建樓閣」。

助讀二次第＝密乘的生起次第與圓滿次第。這句把顯密兩邊都收在菩提心之上。

原文〔0774b08–b11〕

若相續中，略能生起菩提心相，當如儀受勤學學處，堅穩願心。次當聽聞菩薩所有諸廣大行，善知進止，發生猛利樂修學欲。發此心已，當如法受行心律儀，學習六度成熟自身，學四攝等成熟有情，尤當勤猛捨命防範諸根本罪，中下纏犯及諸惡作，亦當勤防莫令有染。若有誤犯，應勤還出。

白話§11

如果在相續中稍能生起菩提心的相，應當如儀軌受（願心），勤學學處，堅穩願心。接著應當聽聞菩薩所有的廣大行，善知進止，生起猛利樂於修學的意欲。生起這心之後，應當如法受行心律儀，學習六度以成熟自身，學習四攝等以成熟有情。尤其應當勇猛地捨命防範各種根本罪；中、下品纏所犯以及各種惡作，也應當勤加防護，不讓染污。如果誤犯了，應當勤加還出。

詳解（1）

願心與行心

論文明說先「如儀受勤學學處，堅穩願心」；再「如法受行心律儀」，學六度熟自、學四攝熟他。

助讀根本罪＝菩薩戒的他勝處法；中下纏犯＝以中品、下品煩惱纏而犯；惡作＝較輕的違犯。還出＝依法懺悔還淨。

原文〔0774b11–b14〕

次當特學最後二度，故當善巧修靜慮法引發正定。又於相續當生清淨遠離斷、常二無我見，得彼見已，應住見上善知清淨修法而修，即於如是靜慮、般若立止、觀名，非離後二波羅蜜多，而為別有。故是正受菩薩律儀，學彼應學從中分出。

白話§12

接著應當特別學習最後二度。所以應當善巧修習靜慮的方法，引發正定。又應當在相續中生起清淨、遠離斷常二邊的二無我見；得到那個見之後，應當安住在見上，善知清淨的修法而修。就在這樣的靜慮與般若上，立止、觀之名，並不是離開後二波羅蜜多而另外有。所以（止觀）是從正受菩薩律儀後所學的應學之處中分出來的。

詳解（1）

止觀＝後二度

論文明說「即於如是靜慮、般若立止、觀名，非離後二波羅蜜多，而為別有」；「是正受菩薩律儀，學彼應學從中分出」。

助讀這句把整個「奢摩他、毘缽舍那」兩章定位在菩薩行之內：止觀不是獨立於菩提心與六度之外的禪修技術，而是受了菩薩戒之後要學的靜慮度與般若度。

助讀「遠離斷、常二無我見」：二無我＝補特伽羅無我與法無我；離常邊（不增益自性）也離斷邊（不損減緣起），正是前面幾十天決擇正見的要點。

原文〔0774b14–b15〕

此復若能修習下下，漸於上上增欲得心，聽聞上上而於下下漸欲修行，是最切要。若於前者全無所有，專修心住，專樂見解，難至宗要，故須對於圓滿道體引生定解。

白話§13

而且，如果能在修習下下（之法）時，漸漸對上上（之法）增長欲得之心；在聽聞上上（之法）時，對下下（之法）漸漸想要修行，這是最切要的。如果對前面的（各法）全都沒有，專修心住，或專樂見解，難以到達宗要，所以必須對圓滿的道體引生定解。

詳解（1）

上下相引

論文明說修下下 → 增上上欲得心；聞上上 → 於下下漸欲修行。

論文明說前面全無，而「專修心住，專樂見解，難至宗要」：只修定或只愛談見，都不能到達要點。

助讀這正好對應讀者的情況：深入辨析各派見地之餘，前面的道次第仍要一起修。

原文〔0774b15–b17〕

修彼等時，亦當聰利令心平等，謂於引導修道知識，敬心微劣，則斷一切善法根本，故當勤修依師之法。

白話§14

修這些的時候，也應當聰利，讓心平等。就是：如果對引導修道的善知識，恭敬心微弱，就斷了一切善法的根本，所以應當勤修依師之法。

原文〔0774b17–b20〕

如是若心不樂修行，當修暇滿，若著現法當修無常、惡趣過患以為主要。若覺漫緩所受佛制，當自思惟是於業果定解劣弱，則以修習業果為主。若於生死缺少厭患，求解脫心則成虛言，故當思惟生死過患。若凡所作，皆為利益有情之心不猛利者，是則斷絕大乘根本，故當多修願心及因。

白話§15

像這樣，如果心不樂於修行，應當修暇滿；如果貪著現世，應當以修無常、惡趣過患為主。如果覺得對所受的佛制戒律漫不經心，應當自己思惟：這是對業果的定解劣弱，就以修習業果為主。如果對生死缺少厭患，求解脫的心就成了空話，所以應當思惟生死過患。如果所做的一切，為了利益有情的心不猛利，這就斷絕了大乘的根本，所以應當多修願心以及它的因。

詳解（1）

依心病調藥

拆開看：不樂修行→暇滿｜著現法→無常、惡趣｜漫緩佛制→業果｜缺厭患→生死過患｜利他心不猛利→願心及因。

助讀願心之因＝能生起菩提心的修法，如知母、念恩等七因果，或自他相換。以原文為準。

原文〔0774b20–b21〕

若受佛子所有律儀，學習諸行而覺執相繫縛猛利，當以理智，破執相心一切所緣，而於如空如幻空性，淨修其心。

白話§16

如果受了佛子的一切律儀、學習諸行，而覺得執相的繫縛很猛利，應當以理智破除執相之心的一切所緣，在如虛空、如幻的空性上淨修其心。

詳解（1）

行中執相，用見對治

論文明說「執相繫縛猛利」→「以理智，破執相心一切所緣」→「於如空如幻空性，淨修其心」。

助讀如空＝根本定中對空性的體會（只是遮除自性）；如幻＝出定後見諸法顯現而無自性。破的是「執相心的所緣」，即所執的自性，不是破六度行本身——這是前面一再強調的。

原文〔0774b21–b23〕

若於善緣心不安住為散亂奴，則當正修安住一趣，是諸先覺已宣說者。以彼為例，其未說者亦當了知。總之，莫令徧於一分，令心堪修一切善品。

白話§17

如果對善所緣心不能安住，成了散亂的奴僕，就應當正修安住一趣。這些都是先前覺者們已經宣說的。以這些為例，那些沒說到的也應當了知。總之，不要讓心偏於一分，要讓心能夠修一切善品。

詳解（1）

不偏一分

論文明說「莫令徧於一分，令心堪修一切善品」。

助讀這和第68天結尾「若無甚深或無廣大，僅於一分，不應執為如是便足」前後相應。

原文〔0774b24〕

已釋上士道次第中學菩薩行，應如何學慧性毘缽舍那之法。

白話§18

已經解釋完上士道次第中學菩薩行時，應當如何學習慧性毘缽舍那的方法。

詳解（1）

章末

論文明說「慧性毘缽舍那」：毘缽舍那的體性是慧，即般若度。

助讀毘缽舍那章到這裡結束。這一句把整章放回「上士道—學菩薩行」的位置上：止觀是菩薩六度中的後二度。

五題，點選答案即顯示對錯與說明；只在這支手機上記錄，不會送出。

1．「猶如小魚游安靜水」所比喻的情形，宗大師怎麼看？

答案：B　論文：「是故唯於未壞堅穩無分別住，兼能觀察無我空義，猶如小魚游安靜水，不當誤為止觀雙運。」〔0774a19〕

2．已成奢摩他、還沒成就毘缽舍那之前，觀察有什麼限制？

答案：C　論文：「若已成就奢摩他後，毘缽舍那未成之前，觀察自力不能引發堅穩安住專注一趣」。〔0774a17〕

3．在「道之總義」中，宗大師怎麼定位止與觀？

答案：D　論文：「即於如是靜慮、般若立止、觀名，非離後二波羅蜜多，而為別有。故是正受菩薩律儀，學彼應學從中分出。」〔0774b12〕

4．論文說，如果沒有大菩提心，六度行與二次第會怎樣？

答案：A　論文：「若無此心，其六度行、二次第等，皆如無基而建樓閣。」〔0774b07〕

5．受菩薩律儀、學習諸行時，若覺得執相繫縛猛利，應當怎麼修？

答案：B　論文：「當以理智，破執相心一切所緣，而於如空如幻空性，淨修其心。」〔0774b21〕
