第六章 · 色之概要與涅槃

前五章講「名法」（心與心所）；本章轉向第三究竟法「色」——28 種剎那生滅、成聚而起的物質法，並以唯一的無為法「涅槃」收束四究竟法。阿耨樓陀對四究竟法的分析部分（前六章），至此圓滿。

本章定位

前五章講的都是「名法」——心與心所。第六章轉向第三種究竟法「色」(rūpa)，即物質現象，共 28 種；最後再以第四種、也是唯一的無為法「涅槃」(nibbāna) 收束四究竟法。至此，阿耨樓陀對四究竟法的分析部分（前六章）宣告完成。

「色」不是常識裡堅實的物質塊，而是 28 種剎那生滅、成組出現的物質性法。連我們的身體，也只是這些色法依業、心、時節、食四因不斷生起的動態聚合。

壹 · 二十八色

28 色分兩大類：具體色 18（有自性、可為觀智所緣）與非具體色 10（較抽象，是前者的性質、界限或相狀）。

一、具體色 18（nipphanna-rūpa）

類數內容
四大種 mahābhūta4地（硬）・水（流/黏）・火（暖）・風（動/支）
五淨色 pasāda5眼・耳・鼻・舌・身淨色（五根的敏感物質）
四境色 gocara4色・聲・香・味（觸即地火風，不另立）
二性根色 bhāva2女根・男根
心色1心所依處 hadaya-vatthu
命色1命根色 jīvitindriya（維持俱生色法）
食色1食素／段食 ojā

二、非具體色 10（anipphanna-rūpa）

類數內容
限制色1空界 ākāsa-dhātu（色聚之間的界限）
表色 viññatti2身表・語表（心藉以表達的身動與語音）
變化色 vikāra3輕快性・柔軟性・適業性（＋二表，合稱五變化）
相色 lakkhaṇa4積集 upacaya・相續 santati・老 jaratā・無常 aniccatā
觸為何不另立？「觸境」就是地、火、風三大（硬軟、冷熱、推動），身根一觸即知，故不另立「觸色」。又：四相色中的「積集＋相續」即色法的「生」，「老」是住異，「無常」是滅——這正是一切色法剎那「生住滅」的印記，也是修觀所要現見的無常。（參菩提比丘 CMA）

貳 · 色聚：物質的最小團

色從不單獨生起，總是成「聚」(kalāpa) 而生。任何一個色聚，最少都含「純八法」——八個不可分離的色 (avinibbhoga)：

地・水・火・風・色・香・味・食素（ojā）——這八法在一切色聚中必定俱在、缺一不可，是物質的「最小公倍數」。
要點：連一粒微塵、一滴水，都至少是這八法的聚合；其餘色（如淨色、性根、命根）則在特定色聚中附加於這八法之上。全論列有 21 種色聚（業生9、心生6、時節生4、食生2）。這說明「物質」在阿毗達磨中不是連續的實體，而是成組、剎那生滅的法聚——為「色無常、無我」提供了微觀基礎。

參 · 色的四種等起

一切色法皆由四種原因之一生起（samuṭṭhāna）：

等起巴利說明
業生色kammaja過去業所生（如五淨色、性根、心色、命色）
心生色cittaja當下心所生（如身表、語表、隨心而動的身體）
時節生色utuja火界（溫度）所生（如身外一切無情色）
食生色āhāraja段食（食素）所生（滋養色身）
身心相依：我們的色身，每一剎那都由這四因共同支撐——業給了根身的底子，心牽動它的表情動作，溫度與飲食維持它的存續。「心生色」尤其值得留意：心念直接生起色法，這是身心互動、乃至修定影響色身（如禪悅轉身）的教理根據。

肆 · 涅槃

涅槃是四究竟法中唯一的無為法——非緣生、無生滅，是脫離有為苦的究竟寂靜。它可從三個角度說：

分法內容
依自性 · 一唯一「寂靜相」(santi-lakkhaṇa)——涅槃只有一，不可分
依上下文 · 二有餘依涅槃 sa-upādisesa（阿羅漢在世，煩惱已盡而五蘊猶存）／無餘依涅槃 anupādisesa（五蘊亦捨、不再相續）
依行相 · 三空 suññata（離貪瞋癡）／無相 animitta（離一切有為相）／無願 appaṇihita（離願求）
關鍵辨正（參 CMA）：涅槃不是「斷滅」（無），也不是「另一個世界」，而是「有為的止息」——貪瞋癡永滅、生死不再相續的無為寂靜。它以自性存在，是出世間道果心所緣的唯一對象（第一章出世間 8 心即以涅槃為所緣）。「有餘／無餘」不是兩個涅槃，而是同一寂滅在「五蘊未捨／已捨」兩種情況下的稱呼。

攝義論選文 · 第六章

核心根本偈（巴利為公有原典，中譯採尋法比丘《精解》用語）。消文為本頁自撰，參菩提比丘 CMA。

共 2 段核心偈頌

一、色為二種

Bhūta-pasāda-visayā bhāvo hadayam icc' api / Jīvitāhārarūpehi aṭṭhavīsati rūpāni.大種、淨色、境色、性根色、心色，以及命色、食色——色共二十八。

消文
此偈列出具體色 18 的骨幹：四大種是一切色的基礎，其餘皆「所造色」，依大種而有。大種如大地，所造色如依地而長的草木。把「物質」拆成 28 種剎那生滅、成聚而起的法，正是要破除「有一個堅實、常住的身體或物質」的錯覺——身體只是色法依四因不斷生起的動態過程。（參菩提比丘 CMA）

二、涅槃的三種說

Tad etaṃ sabhāvato ekavidham pi… sa-upādisesa-nibbānadhātu anupādisesa-nibbānadhātu cā ti duvidhaṃ… suññataṃ animittaṃ appaṇihitañ cā ti tividhaṃ.此（涅槃）依自性雖一，依上下文則二（有餘依、無餘依），依行相則三（空、無相、無願）。

消文
涅槃自性唯一（寂靜），但可從不同角度稱說：就「阿羅漢五蘊在否」分有餘、無餘；就「以何行相趣入」分空（觀無我而入）、無相（觀無常而入）、無願（觀苦而入）。這三行相正對應三解脫門，也對應觀智所偏重的三共相。涅槃非斷滅、非他界，而是貪瞋癡永滅的無為寂靜，是全部修道的歸趣——阿毗達磨對四究竟法的分析，至此圓滿收束於此。（參菩提比丘 CMA）

本章修學重點

身體是動態的色聚

色身不是常住實體，而是 28 色依業心時節食四因剎那生滅的聚合。這是「觀身無常、無我」的微觀依據。

心能生色

「心生色」點出身心互動：心念直接牽動色法。修定影響色身、禪悅轉身，皆由此可解。

涅槃是止息，非斷滅

涅槃是貪瞋癡永滅的無為寂靜，以自性存在，為出世間心所緣。非無、非他界。

學習考題 · 自我驗收

一、單選題

1阿毗達磨列舉的「色」共有幾種？如何分類？

答案：B。28 色 = 具體色 18（大種4＋淨色5＋境色4＋性根2＋心色1＋命色1＋食色1）+ 非具體色 10（空界1＋表2＋變化3＋相色4）。

2為什麼「觸境」不另立為一種色？

答案：C。觸境（硬軟、冷熱、推動）就是地、火、風三大，身根一觸即知，故四境色只列色聲香味，不另立觸色。

3任何一個色聚（kalāpa）中，必定俱在、缺一不可的「純八法」是？

答案：A。純八法（avinibbhoga）＝四大種＋色、香、味、食素，在一切色聚中必定俱在，是物質的最小組合。

4下列何者不是色法生起的四種原因（等起）之一？

答案：D。四因生色是業、心、時節、食。虛空（空界）本身是被生的一種非具體色，不是生色之因。

5「有餘依涅槃（sa-upādisesa）」指的是？

答案：B。有餘依＝煩惱已盡、五蘊（身）猶存（阿羅漢在世）；無餘依＝五蘊亦捨、不再相續。二者是同一寂滅的兩種情況，非兩個涅槃。

二、是非題

6依阿毗達磨，我們的身體是一個常住、堅實的物質實體。

答案：錯誤。身體是 28 色依業、心、時節、食四因剎那生滅、成聚而起的動態聚合，並非常住實體。這正是「觀身無常、無我」的微觀依據。

7「心生色（cittaja-rūpa）」意味著心念可以直接生起色法，是身心互動的教理根據。

答案：正確。四因生色含「心生色」——身表、語表及隨心而動的身體皆由心生，這是修定影響色身、禪悅轉身的教理基礎。

8涅槃是一切都歸於「空無、斷滅」，什麼也不存在。

答案：錯誤。涅槃是貪瞋癡永滅、生死不再相續的「無為寂靜」，以自性存在、為出世間心所緣，非斷滅、非虛無、也非另一個世界。

三、思考題（不計分）

思考題一：把身體看成「28 色依四因剎那生滅的色聚」，對修「不淨觀」「界分別觀」有什麼幫助？

（供省思）界分別觀正是把身體拆解為地水火風四界（乃至 28 色），現見其中並無「我、我所、可貪之相」，只有生滅的法。色聚論給這種觀法一張精密地圖：知道身體只是成組生滅的物質法，貪身、我執便失去立足點。這與《清淨道論》的四界差別、三十二身分觀直接相通（第九章業處）。

思考題二：南傳「涅槃以自性存在、有寂靜相」，與中觀「涅槃亦空、無自性」看似衝突。你怎麼理解這組張力？

（開放題）這是部派實在論與大乘中觀最深的一組對話。南傳為維護「涅槃是真實可證的無為法、非斷滅」，說它「以自性存在」；中觀為徹底破執，連涅槃也說「無自性、與世間無異」（《中論》涅槃品）。兩者關切不同：一者防「斷見」（涅槃是無），一者防「常見／法執」（涅槃是實有一物）。深入對讀，正是理解「二諦」與「空」的絕佳入口。

思考題三：本章一併處理「色」與「涅槃」——一個是最粗的有為物質，一個是最細的無為寂靜。阿耨樓陀把它們放在同一章，有什麼深意？

（供省思）這正凸顯四究竟法的「有為／無為」二分：心、心所、色三者皆有為、皆苦、皆當「遍知」；涅槃無為、是苦的止息、當「證」。第六章以「最粗的色」始、以「無為涅槃」終，恰是把「所應遍知的有為」與「所應趣證的無為」並列——分析的終點，正指向修證的起點。這也預告了後三章從「理論」轉向「實修」。
