臨終那一刻，你的「雲端」會推播什麼給你？

文/孫彩玲

現代人都有這個經驗：前幾天搜尋了登山鞋，接下來整個螢幕，都是登山鞋。

你平常搜尋、點擊最多的，手機就推播最多的。

有趣的是，臨終的時候，也有類似的事情發生。

一、臨終前，會出現三種畫面

依《攝阿毗達摩義論》，臨終的人，從六根（眼、耳、鼻、舌、身、意）常會浮現三種顯像之一：

  • 業：過去做過的行為，重新浮現。可能是一件印象很深的事，也可能是長年慣常的作為。常幫助別人的人，心中浮現的多半是助人的畫面。
  • 業相：與那個業有關的象徵物。可能是念佛機、佛像，也可能是酒瓶、撲克牌。
  • 趣相（未來去向的景象）：可能是蓮花、光明，也可能是火焰、黑暗。

這些畫面，並非毫無來由。一般來說，就像手機的推播，你平常餵什麼，它就推什麼。（若這一生造過極重的善惡業，那件事會優先浮現，不受日常習慣影響。）

差別在於：手機背後有演算法在推；臨終時，背後沒有任何人。推播的內容，是你自己這一輩子，一點一滴「餵」出來的。

二、這些「資料」，存在哪裡？

肉體可以火化成灰，大腦、神經都沒了，記憶體也跟著消失。

但佛法說，推動生死相續的根本力量，是兩樣火燒不掉的東西：無明，與愛。它們推著心識與業力，繼續相續下去。

這個過程，可以想像成一個雲端帳號：

  • 你這一生的每個念頭、言行，都像自動上傳、自動同步。
  • 不用帶任何東西，換了手機（換了身體），帳號和資料都還在。

依大乘唯識的講法，帶著這個帳號離開的，是第八識（阿賴耶識）。它不是放在哪個地方等人來開，因為它就是你心識的相續本身。

臨終時，前六識逐漸停止，第八識帶著所有的種子離開身體，進入「中陰身」的階段。接下來去向哪裡，要看哪一顆種子先成熟。一般的順序是：重業優先，其次是臨終業，再來是習慣業，最後才輪到過去其他所作的業（已作業）。

向上，是三善道（天、人、阿修羅）；向下，則是三惡道（畜生、餓鬼、地獄）。

淨土法門還有一條特別的路：臨終一心念佛、與阿彌陀佛感應道交的人，由佛接引，蓮花化生，不必經過中陰身。

三、三個提醒，讓比喻不走偏

第一，雲端不是一個「外面的倉庫」。 宇宙某處沒有伺服器，也沒有人在看管。業力是你自己心識的相續，不是存在別處的檔案。

第二，也沒有一個固定不變的「你」，在持有這個帳號。 帳號本身，就是不斷變化、前後相續的心識之流。

第三，這個帳號，每一刻都在更新。 它不是存好就不動的舊檔案，而是活的。已經存進去的，改不了；但今天一個善念，就是新增一筆；今天一次覺察，就是調整一次未來推播的方向。

這也是為什麼說：命運始終握在自己手裡。

四、所以，從今天開始「訓練」未來的推播

既然平常餵什麼，臨終就推什麼，那麼：

  • 常常念佛，就是在餵「阿彌陀佛」。
  • 常常感恩，就是在餵「安心」。
  • 常常抱怨、比較，也會被忠實地記錄下來。

今天的每一個點擊，都在設定你最後的那個首頁。

而念佛的人，臨終並不是一個人面對，還有阿彌陀佛的願力接引。
